Stream Deck
Comment régler une touche

Chaque touche appelle une adresse. Dans Bitfocus Companion : module « Generic HTTP Requests », action « GET », puis colle l'adresse. Avec le logiciel Elgato : un plugin de requêtes web (« Web Requests », « API Ninja »…). Le chrono et le score sont calculés par le serveur : la régie n'a pas besoin d'être ouverte.

Les adresses « Image » (en bas de la liste) donnent une image à afficher sur la touche : le score sur la couleur de l'équipe, ou son logo. Dans Companion : module « Generic HTTP », retour (feedback) « Image from URL », avec un rafraîchissement d'une seconde pour le score. Ajoute &format=texte pour obtenir juste le chiffre.

Générer une nouvelle clé ? Toutes les touches déjà réglées cesseront de fonctionner.
